## Purpose and contents

This repository holds organization-wide GitHub community health files. GitHub can apply supported root-level files (such as `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and issue templates) to repositories that do not provide their own. The [organization profile README](profile/README.md) is maintained separately and introduces Companion Intelligence projects.

| Path | Role |
|---|---|
| `profile/README.md` | Public organization profile |
| `CREDITS.md`, `NOTICE.md`, `THIRD_PARTY.md` | Attribution and third-party notices |
| `LICENSE.md` | License information for this repository's content |

When adding a shared policy, verify that it is appropriate for every repository that inherits it; project-specific instructions belong in that project's own repository.
