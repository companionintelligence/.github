# Companion Intelligence

**Open-source tools for private, local-first AI companions.**

[Website](https://ci.computer) · [Documentation](https://docs.ci.computer) · [Marketplace](https://hub.ci.computer/store) · [All public repositories](https://github.com/orgs/companionintelligence/repositories?type=public)

</div>

Companion Intelligence is built to run on hardware you own. Companion Hub installs and runs your apps and agents, and Companion Memory is the personal data layer underneath them. The apps below add capture, spatial experiences, devices, and tools around those two.

## Apps

Find the app, then pick your platform. Every link goes to an official store listing, a GitHub release file, or a live web app. "Coming soon" means the app is not public yet.

**Companion** opens the app in the Hub Marketplace, where you install it into your own Companion Hub. **Info** opens the product page. Browse the full catalog at [hub.ci.computer/store](https://hub.ci.computer/store).

## How the pieces fit

Solid arrows show data or service flows. Dotted arrows show supporting relationships.

```mermaid
flowchart LR
    HUB["Companion Hub"] <--> MEM["Companion Memory"]
    STORE["Hub Marketplace"] -. "apps and agents" .-> HUB
    VOICE["Companion Voice for Home Assistant"] <--> HUB

    CAP["Companion Capture"] -->|"desktop activity"| MEM
    BROWSER["Browser Extension"] -->|"browser context"| MEM
    MEM -->|"alerts and triggers"| PEBBLE["Pebble"]
    MEM -->|"located memories"| ATLAS["Companion Atlas"]

    classDef core fill:#0f717a,stroke:#0b565c,color:#fff
    class HUB,MEM core
```
